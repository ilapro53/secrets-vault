🔐 Secrets Vault

Command-bound OTP · окно 5 мин
Введи имя секрета из pass, например: ssh/deploy, github/token
Скопируй команду от агента целиком и вставь сюда как есть
❓ Как это работает?
Агент присылает команду вида: secrets-bash-executor --secrets VAR1,VAR2 - <<'SCRIPT' ... script with $VAR1, $VAR2 ... SCRIPT Ты копируешь ВСЁ это (от "secrets-bash-executor" до "SCRIPT") и вставляешь сюда. Приложение вычисляет код на основе всего текста команды. Если изменить хоть букву — код станет другим. Код привязан к конкретному скрипту + времени (окно 5 мин).
-------------
← текущий (действителен 5 мин) ← следующий (можно заранее)
Обновится через 5м 00с
Скажи агенту оба кода: XXXXXX-YYYYYY
При первом использовании — получи secret key через
sudo secrets-uri на сервере и вставь выше.

Можно передать ключ через URL: ?key=SECRET
(сохраняется в localStorage, вводить повторно не нужно)
